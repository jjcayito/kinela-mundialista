# Guia Admin

## Flujo Diario

1. Entrar a `/admin` y colocar la clave admin.
2. Abrir o cerrar fases en `/admin/phases`.
3. Revisar partidos en `/admin/matches`.
4. Confirmar resultados en `/admin/results`.
5. Ajustar reglas en `/admin/scoring` si la organizacion cambia el puntaje.
6. Descargar Excel en `/admin/export`.
